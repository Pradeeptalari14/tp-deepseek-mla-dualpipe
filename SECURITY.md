# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within DeepSeek-R1 MLA & DualPipe Engine, please report it privately.
Do not disclose vulnerabilities publicly via GitHub Issues.

- **Email**: `security@talari.dev` or open a private security advisory on GitHub.
- **Response SLA**: Initial triage within 24 hours; remediation patch within 72 hours.
